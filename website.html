Frequently Asked Questions

Is ClicoClicker free?

Yes, ClicoClicker is completely free and open source under the MIT license.

How do I run it on Linux?

Download the .deb package and install it using:

sudo dpkg -i clicoclicker_1.0.0_amd64.deb

Can I contribute to the project?

Yes! The project is open source on GitHub. Feel free to submit issues, features, or pull requests.
